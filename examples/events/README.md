# Example events

Synthetic security events, one JSONL file per scenario. Generated by [scripts/generate_events.py](../../scripts/generate_events.py). Do not edit by hand, CI checks that these files match the generator.

- IPs are from documentation ranges (RFC 5737). ASNs are from the documentation range (RFC 5398).
- Users, devices, accounts, and amounts are fake.
- Timestamps start at a fixed date so tests are deterministic. Shift them to the current time before replaying into a SIEM test index.

Use these for rule logic tests and SIEM pipeline tests only. Replay into a test index, never into production.

| File | Pattern |
| --- | --- |
| credential-stuffing.jsonl | One IP, 40 users, two successes |
| password-spray.jsonl | Six IPs in one ASN, 45 users, one attempt each |
| brute-force-single-account.jsonl | One user, 14 failures from 5 IPs, then lock |
| mfa-fatigue.jsonl | Four denied pushes, then approval |
| device-change-then-transfer.jsonl | New device bound, new beneficiary, transfer |
| reset-flood.jsonl | 30 reset requests from one IP, most for unknown accounts |
| session-hijack.jsonl | Session moves from PK to BR mid session |
| object-level-probe.jsonl | One user denied on 20 accounts owned by others |
| admin-route-probe.jsonl | Customer role calling admin and management routes |
| mass-assignment.jsonl | Profile updates carrying role and limit fields |
| bulk-export.jsonl | 12 pages of 500 customer records |
| account-takeover-chain.jsonl | Failures, login, mobile number change, beneficiary, transfer |
| limit-raise-drain.jsonl | Limit raised, then two large transfers |
| below-threshold-transfers.jsonl | Six transfers just under a step up threshold |
| tampered-amounts.jsonl | Negative, zero, and over precision amounts |
| promo-abuse.jsonl | Four accounts redeem one signup promo from one device |
| scanner-noise.jsonl | 30 validation failures across routes, plus parser errors |
| insider-lookups.jsonl | Support agent reads 60 customers, 57 without a ticket |
| privileged-grant.jsonl | Staff member grants a privileged role to self |
| config-change.jsonl | MFA enforcement turned off |
| refresh-token-reuse.jsonl | Rotated refresh token presented from a new IP |
| idempotency-conflict.jsonl | Same key, different amount |
